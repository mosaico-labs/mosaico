The C++ SDK is currently in active design.

We are building it to match the capabilities of the Python SDK, with a focus on low-latency, embedded, and resource-constrained deployments where a native C++ client is required.

If you have a specific application or integration that depends on a C++ client, we would like to hear from you. Knowing your use case helps us prioritize the API surface and platform targets that matter most.

Reach out directly at [hello@mosaico.dev](mailto:hello@mosaico.dev).
