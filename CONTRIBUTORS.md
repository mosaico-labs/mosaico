# Contributors

This file lists the external contributors who have signed the Mosaico
[Contributor License Agreement (CLA)](CONTRIBUTING.md#contributor-license-agreement-cla).

We can only merge a Pull Request if its author appears in this list. The
**Contributors** check enforces this rule by blocking Pull Requests from
first-time contributors who are not listed. Maintainers, bots and anyone who
already has a commit in the repository skip the check, since they have
already signed the CLA.

## How to be added

1. Open your Pull Request
2. Sign the CLA when a maintainer asks you to
3. A maintainer adds your GitHub username to this file in a separate Pull
   Request
4. Re-run the **Contributors** check on your Pull Request

Do not add yourself to this file in your own Pull Request: the check only
reads the list from the target branch.

## Format

Each entry is a GitHub username prefixed by `@`, one per line, in a bullet
list. Usernames are case-insensitive.
